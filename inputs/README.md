# Synthetic data

All data in this repository are synthetic and dimensionless. No experimental,
personal or external observational dataset is required.

`experiment.json` specifies the equations, parameters, grid sizes, observation
times, solver steps/tolerances and test seeds. It documents the fixed implemented
experiment; editing the JSON alone does not configure a new simulation.

`initial_conditions.npz` stores numerical preparations for the production,
independent audit and supplementary affine calculations:

- `particle_nN_kK_x0` and `particle_nN_kK_g0`: lifted positions and mean-one gaps,
  where the value after `n` is the cube root of the particle count.
- `cell_aA_mM_kK`: production cell states of shape `(A, M+1)`, with `X0` in the
  first column and `G0` in the remaining columns.
- `audit_cell_aA_mM_kK`: analogous states generated by the independent initializer.
- `mean_aA_x0_q0`: two-column arrays for the macroscopic map and its derivative.
- `times`, `uniform_times`, `response_times`: the output meshes.

The solvers regenerate these analytic preparations internally. Before a full
run, the software verifies that the bundled arrays and settings match that
deterministic generation. Thus the supplied inputs are auditable snapshots,
not a hidden dependency or substitute for recomputation. The initial state of
the particle solver is also checked directly against a saved preparation in
the test suite. Quadrature-only profiles are generated from the same formulas
at their required nodes.

To recreate the synthetic files in a new directory:

```bash
python -m gap_arrangement synthetic --output-dir generated
python -m gap_arrangement check-inputs --inputs-dir generated/inputs --output-dir input-check
```

To inspect an archive, use `numpy.load(path, allow_pickle=False)`. Expected output
curves and summary data, which are distinct from initial conditions, are supplied
in `reference/`.
